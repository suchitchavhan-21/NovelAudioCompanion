About Novel Audio Companion

An open-source, community-driven text-to-speech and distraction-free reading companion designed specifically for web and light novel enthusiasts.

Project Overview & Description

Novel Audio Companion (NAC) bridges the gap between ad-cluttered web novel sites and true audiobook-quality narration. General browser speech tools frequently freeze after 15 seconds, mispronounce fantasy terminology, fail across chapter boundaries, and lack lock-screen media controls. NAC provides a specialized, privacy-focused client engine that sanitizes novel chapters, maintains uninterrupted speech, and provides an immersive reading canvas.

Core Technical Pillars

🎙️ Continuous Audio Narration

Duration-aware keep-alive heartbeat eliminates Chromium's 15-second speech silence bug without periodic audio stutters. Features natural sentence and paragraph pauses for human-like cadence.

📖 ReDoS-Protected Phonetic Dictionary

Replaces cultivation Pinyin, fantasy names, and LitRPG stat tags before speech begins. Equipped with regex pattern boundaries and safe execution wrappers.

👁️ Distraction-Free Reader Mode

Kindle-inspired reading surface with 4 high-contrast themes (Midnight, OLED Pitch Black, Cozy Sepia, Clean Daylight) and accessible typography.

🎧 Hardware & Lock-Screen Media Keys

Native W3C Media Session API integration enables play/pause and paragraph navigation directly via Bluetooth headsets, earbuds, or lock-screen controls.

Source Code & Community

Novel Audio Companion is fully open-source and respects user privacy—no external tracking, no telemetry, and all settings are stored locally or synced via Chrome Sync.
